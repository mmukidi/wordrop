# Capacitor 6 → 8 + Swift Package Manager migration

Done 2026-08-02. **Two manual Xcode steps are still required** — see
"What you must do on the Mac" below. Until those are done the app will not
build.

## ⚠️ Hard requirement: Xcode 26.0

**Capacitor 8 requires a minimum of Xcode 26.0** (and Node 22+). Check before
you rebuild:

```bash
xcodebuild -version     # must be 26.0 or newer
node --version          # must be v22 or newer
```

If you are on an older Xcode, **do not build this branch** — roll back with:

```bash
cd /Users/manu/Desktop/projects/wordrop
git revert --no-commit HEAD && git checkout -- . && npm install
```

## Why this was needed

The project was in a broken hybrid state:

- JS packages were Capacitor **6.2.1**
- Xcode linked `capacitor-swift-pm` **8.4.2** via SPM
- A `Podfile` existed but CocoaPods had never actually run — both
  `Podfile.lock` and `Pods/Manifest.lock` were stubs containing
  `PODFILE CHECKSUM: 12345` and an empty `PODS:` list

Only the `Capacitor` and `Cordova` products were linked to the App target.
**`CapacitorHaptics`, `CapacitorShare` and `CapacitorLocalNotifications` were
not linked at all**, so at runtime `window.Capacitor.Plugins.Haptics` was
`undefined` and every haptic, the Share button and the streak reminder
silently no-opped.

`GameCenterPlugin.swift` was unaffected — it is a plain source file compiled
directly into the App target, which is why Game Center worked while the
plugin-backed features did not.

## What changed in the repo

| Change | Detail |
|---|---|
| JS packages | core/cli/ios → **8.5.0**; haptics 8.0.2, share 8.0.1, local-notifications 8.2.1, status-bar 8.0.3 |
| iOS deployment target | 14.0 → **15.0** (Capacitor 8 minimum) |
| `ios/App/CapApp-SPM/` | **new** — the SPM aggregator package that links all plugins |
| `ios/debug.xcconfig` | **new** — sets `CAPACITOR_DEBUG` |
| `ios/App/Podfile`, `Podfile.lock`, `Pods/`, `App.xcworkspace` | **deleted** — vestigial, and actively misleading when diagnosing |
| `Package.resolved` | deleted so Xcode re-resolves (it pinned the stale 8.4.2) |

`CapApp-SPM/Package.swift` is generated by the CLI — **do not edit it**. It
now reads:

```swift
dependencies: [
    .package(url: ".../capacitor-swift-pm.git", exact: "8.5.0"),
    .package(name: "CapacitorHaptics", path: "../../../node_modules/@capacitor/haptics"),
    .package(name: "CapacitorLocalNotifications", path: "..."),
    .package(name: "CapacitorShare", path: "..."),
    .package(name: "CapacitorStatusBar", path: "...")
]
```

The existing remote `capacitor-swift-pm` reference in the Xcode project is
`upToNextMajorVersion` from 8.4.2, which 8.5.0 satisfies — so there is **no
version conflict** with `CapApp-SPM`'s `exact: "8.5.0"`.

Keep the direct `Capacitor` and `Cordova` product links on the App target:
`CapApp-SPM.swift` is only a marker (`public let isCapacitorApp = true`) and
does **not** re-export Capacitor, while `AppDelegate.swift` and
`GameCenterPlugin.swift` both `import Capacitor`.

## What you must do on the Mac

```bash
cd /Users/manu/Desktop/projects/wordrop
npm install
npx cap sync ios
npx cap open ios          # opens App.xcodeproj (the .xcworkspace is gone)
```

Then, in Xcode:

**1. Add the local CapApp-SPM package**

- Select the **App** project in the navigator
- Go to the **Package Dependencies** tab
- Press **+**
- Click **Add Local…** in the dialog
- Select the `ios/App/CapApp-SPM` folder → **Add Package**
- On the product screen, click **Add Package** again

**2. Add debug.xcconfig**

- Go to the project's **Info** tab
- Under Configurations, choose **Add Configuration File…**
- Select `ios/debug.xcconfig`
- Choose **xcconfig** when prompted

Then **Product → Clean Build Folder**, and build.

If packages fail to resolve: **File → Packages → Reset Package Caches**.

## Verifying it worked

The whole point of this migration was to make the plugin-backed features
real. After building to a device:

1. **Haptics** — you should feel a light tap on a 3–4 letter clear, medium on
   5+, a heavy thump on a glow-tile row burst, a success buzz on each
   tutorial step and level completion, an error buzz on level failure.
   Requires a real device (not the Simulator), **Settings → Sounds & Haptics
   → System Haptics** on, and **Low Power Mode off**.
2. **Share** — the SHARE RESULT button on the game-over screen should open
   the native share sheet.
3. **Streak reminder** — after finishing a Daily Challenge run, iOS should
   ask for notification permission.
4. **Game Center** — open **📊 GAMER STATS**; there is now a **GAME CENTER**
   row reading `✅ <your name>`, `⚠️ Not signed in`, or `⚠️ Sign-in failed`.
   This replaces having to guess from the two-second welcome banner.

## Known follow-up, not done here

Capacitor 8 ships a `npx cap migrate-uiscene` assistant. This project still
uses the classic `AppDelegate` + `window` lifecycle with no
`UIApplicationSceneManifest`. It builds fine today, but Apple is moving
toward requiring UIScene adoption, so this is worth doing as its own
change — it touches app startup and deserves to be isolated from everything
else in this migration.
